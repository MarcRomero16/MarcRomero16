## 🔬 Featured Project: μTheia — Event-Based Vision ASIC

Technologies: SystemVerilog, Python, cocotb, GF180MCU, OpenROAD, LibreLane

μTheia is a custom ASIC developed as part of my senior VLSI capstone at UC Santa Cruz. Designed for event-based machine vision, the chip processes EVT2 event streams to extract spatiotemporal features and classify motion patterns using an SRAM-backed, integer MAC-based classifier.

Working alongside a team of five, I contributed to the RTL design and verification of the system, with a particular focus on gate-level simulation and timing verification using cocotb and SDF back-annotation.

This project gave me hands-on experience with the ASIC design flow, from hardware architecture and RTL implementation to physical design and post-layout verification.
🔗 [GitHub Repo](https://github.com/MarcRomero16/microTheia)

## 🚀 Key Projects

### 🔢 Tiny MatMul — 2×2 Systolic Matrix Multiplier

Designed a 2×2 systolic matrix multiplier in Verilog for the Tiny Tapeout platform, using multiply-and-accumulate operations to perform matrix multiplication across multiple clock cycles.

Implemented a controller to coordinate diagonal data flow through the systolic array, along with an 8-bit input interface and 16-bit output readback mechanism.

Developed cocotb testbenches to verify functionality through directed, randomized, reset, and edge-case testing.

🔗 [GitHub Repo](https://github.com/MarcRomero16/ttsky-mini-matmul)

### 🧠 Parkinson's Freezing of Gait Prediction — Michael J. Fox Foundation

Collaborated with a multidisciplinary team through Break Through Tech AI to develop machine learning models for detecting Freezing of Gait (FoG) in Parkinson's disease patients using wearable accelerometer data.

Contributed to exploratory data analysis, signal processing using Fast Fourier Transforms (FFT), feature engineering, and recurrent neural network (RNN) development to identify abnormal movement patterns.

Evaluated machine learning approaches, including Random Forest, RNN, and LSTM models. The RNN achieved approximately 92–93% accuracy and a 0.98 ROC-AUC, demonstrating the potential of wearable sensor data for gait monitoring.

🔗 [GitHub Repo](https://github.com/MarcRomero16/MJF-1A-Parkinson-s-Freezing-of-Gait-Prediction)
